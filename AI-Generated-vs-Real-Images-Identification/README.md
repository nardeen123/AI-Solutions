# 📌 Project Overview
With the rise of powerful generative AI models, distinguishing between AI-generated images and real human-captured photos has become a critical challenge. This project focuses on building a robust system to automatically classify images as either AI-generated or real.

The system leverages deep learning and computer vision techniques to train models capable of learning subtle visual cues, artefacts, and inconsistencies commonly found in synthetic media.

# 🏆 Competition Performance
This project was developed and submitted as part of a Kaggle competition on AI-generated vs real image identification.

📌 First public Kaggle competition
📊 Ranked 203 / 554 participants
🎯 Achieved high accuracy on test submissions
🚀 Built strong foundations for future competitive deep learning projects
